# TimezoneOnProfile

### Vencord plugin to add user-specific timezones to profiles and messages.

### Settings:

**Message Time Mode**: Configure what times you would want next to people's usernames, and where:
- Sent time in user's timezone next to messages
- Current time next to messages
- Sent time in DMs, current time in servers

**Time Font Size**: Type in a font size for:
- Username font size (normally 12px)
- Profile font size (normally 14px)

**Clear Saved Timezone History**: Removes timezone data from all users.
